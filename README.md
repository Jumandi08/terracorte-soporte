# Soporte de TerraCorte

TerraCorte es un complemento de Blender, de Jumandi 3D, para llevar un territorio real a una malla lista para cortar.
Aquí se reciben sus dudas y sus fallos.

Este repositorio no contiene el código. El código viaja dentro del archivo del complemento, con su licencia.

## Reportar un fallo

Abre una [incidencia nueva](https://github.com/Jumandi08/terracorte-soporte/issues/new) y cuenta:

1. **La versión de TerraCorte.** Está en Edición › Preferencias › Complementos, en la ficha de TerraCorte.
2. **La versión de Blender y el sistema operativo.**
3. **Qué hiciste,** paso a paso, y qué esperabas que pasara.
4. **Qué pasó.** Una captura de la ventana ayuda.
5. **Las últimas líneas del registro.** En la vista 3D, menú **TerraCorte** › **Registro de TerraCorte**. El archivo
   es `~/.bgis/bgis.log`.

El registro no guarda las claves de los servicios. Aun así, repasa lo que pegues: una incidencia es pública.

## Preguntar

Las dudas se abren igual, como incidencia. Antes de preguntar, mira el archivo `README.md` que viene dentro del
complemento: explica cómo se instala y cómo se usa cada etapa.

## Dónde está validado

En Blender 5.2 LTS, en macOS con Apple Silicon. En Windows, en Linux y en otras versiones de Blender no está
validado: los reportes de ahí se agradecen, y conviene decirlo en el título.
